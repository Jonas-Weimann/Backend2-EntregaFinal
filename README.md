# 🖨️ EXPRINTIFY

**Exprintify** es un proyecto personal que simula un ecommerce de artículos de librería.

Utiliza una API backend creada con **Express** para gestionar productos y carritos de compra, interactuando con una base de datos **MongoDB** para obtener y almacenar información.

Es una solución completa para experimentar con la gestión de productos y la integración de backend en entornos de ecommerce, ideal para quienes desean desarrollar y probar sistemas de ecommerce de manera efectiva.

---

## 🚀 Tecnologías utilizadas

- Node.js
- Express
- MongoDB + Mongoose
- Dotenv
- Handlebars
- CSS
- JavaScript

---

## 📦 Funcionalidades principales

- CRUD de productos, tickets y usuarios
- Gestión de carritos de compra
- Conexión a base de datos MongoDB
- Manejo de rutas API REST
- Controladores desacoplados
- Middleware de errores
- Uso de variables de entorno
- Arquitectura modular
